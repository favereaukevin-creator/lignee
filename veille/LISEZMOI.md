# Gabarit du courriel de veille

`gabarit-courriel.txt` est lu chaque matin par la routine de veille juridique
(`curl` sur raw.githubusercontent.com). Il n'est pas publié sur le site.

Ne pas le modifier à la main : il est généré depuis le dépôt privé
`veille-juridique` (`modele/blocs.mjs`, puis `node modele/squelette.mjs`).
